# Homework – E471 Power System Analysis I

This folder provides a high-level summary of homework assignments completed for **E471 – Power System Analysis I**.  
The assignments focus on analytical foundations and numerical methods used in power system modeling, load flow, and fault analysis.

> Detailed problems and solutions are not publicly shared to comply with academic integrity policies.

---

## Homework 1 – Per-Unit Analysis & Balanced Three-Phase Systems
- Per-unit system formulation with selected power and voltage bases  
- Balanced three-phase circuit analysis  
- Calculation of bus voltages, power flows, and load powers under different transformer tap and voltage conditions  

---

## Homework 2 – Load Flow Theory and Formulation
- Bus classification for load flow analysis (Slack, PV, PQ buses)  
- Identification of unknowns and formulation of power flow equations  
- Derivation of power injection equations  
- Jacobian matrix formulation  
- Newton–Raphson load flow method  
- Fast-Decoupled Load Flow method  
- Analysis of different network topologies  

---

## Homework 3 – Fault Analysis & Symmetrical Components
- Symmetrical (balanced) fault analysis  
- Unsymmetrical fault analysis:
  - Single line-to-ground fault  
  - Line-to-line fault  
  - Double line-to-ground fault  
- Sequence networks (positive, negative, zero)  
- Calculation of fault currents and post-fault voltages  
- Circuit breaker current analysis  

---

## Skills & Concepts Developed
- Per-unit normalization  
- Load flow modeling and solution methods  
- Power system fault analysis  
- Use of analytical and numerical techniques in power systems
